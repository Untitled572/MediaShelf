## 限制与待验收

- 远程 qBittorrent：最初缺少凭据的重复登录触发来源 IP 临时封禁；程序已修复空凭据不提交登录、错误凭据五分钟冷却、正确 Origin/Referer。在用户授权重启后已解封，qBittorrent 5.3 空正文登录兼容修复后，真实读取 186 个任务通过；保留历史分类，新增无分类。
- 当前远程代理连接已通，但 JavDB 搜索返回 HTTP 200 的 Cloudflare 验证页；程序会明确报告需要浏览器验证，不能把它视为作品不存在。JavLibrary 也曾实测受到 HTTP 403 限制。FANZA 按演员姓名发现未获得稳定实测结果，可使用演员目录 URL；不保证任何来源包含演员全部历史作品。不可用或分页中断明确标为未完成。
- 隔离真实 qBittorrent 5.3.0 写入验收通过：使用两条无 tracker 合成磁力链接，先关闭测试实例 DHT/PEX/LSD；验证自动分类/autoTMM、无分类/固定目录、启停、标签、限速回读及移除任务。没有下载影片，用户现有队列未用于写入测试。测试容器已停止，保留其容器记录。
- 外站 iframe 能否显示取决于站点的 CSP/X-Frame-Options，不绕过；隐私模式会阻止 iframe 加载。
- OpenList 只实现按片库前缀跳转，真实挂载前缀尚未逐文件校验，不宣称播放链路通过。
- 模型推荐采用可解释的评分、演员/标签相似度和共演关系；不调用大模型。结果依赖已有目录和评分，空目录不会伪造推荐。
- JSON 备份不含影片、图片或凭据；完整恢复需备份整个数据目录。没有对用户真实数据库执行恢复覆盖。

## 安全边界

设备路径、工具和下载器 URL 必须同时存在于本机白名单。WebUI 无法下发任意程序路径或 shell 参数。所有文件删除开关均被拒绝，只能移除 torrent 任务并保留文件。此范围保留了任务管理功能，未提供媒体删除接口。
