# MediaShelf implementation contract
Independent project. Do not modify existing media or tool projects. Do not read secrets from their configs.
Stack: Go HTTP API and Windows agent; Vue 3 TypeScript Vite UI; SQLite (modernc.org/sqlite). Server :8765.
API JSON snake_case; successful lists are plain arrays. Errors {error:string}. Auth login POST /api/v1/login {password} -> {token}; Bearer token thereafter. Setup password from MEDIASHELF_PASSWORD; refuse default public exposure, server default bind 127.0.0.1:8765.
Entities:
Work {id,code,title,year,actors: string[],tags:string[],rating:number|null,source_rating:number|null,cover_url,source_url,kind,collection_status,files:File[],progress:Progress}
File {id,device_id,library_id,relative_path,size,modified_at,version,missing:boolean}
Progress {compression,cutting,translation,verified:boolean}; step strings pending/in_progress/done/not_needed.
Device {id,name,online,last_seen}; Library {id,device_id,name,path,openlist_base,openlist_prefix}
Tool {id,device_id,name,path,working_dir}; Job {id,device_id,type,payload,status,result,created_at}
GET /api/v1/works?q=&actor=&year=&status=; GET/PATCH /api/v1/works/{id}; PATCH accepts rating, progress,title,actors,tags,collection_status.
GET /api/v1/actors -> [{name,count,policy,target}]; PATCH /api/v1/actors/{name} {policy:complete/selective/follow,target:2}.
GET/POST /api/v1/libraries; GET /api/v1/devices; POST /api/v1/devices {name} -> {id,token}; GET/POST /api/v1/tools; POST /api/v1/tools/{id}/launch; POST /api/v1/libraries/{id}/scan; GET /api/v1/jobs.
Agent endpoints use device Bearer token: GET /api/v1/agent/config -> {device_id,libraries:[],tools:[]}; POST /api/v1/agent/heartbeat {}; POST /api/v1/agent/poll -> Job[]; POST /api/v1/agent/jobs/{id}/result {status,result}; POST /api/v1/agent/scan {library_id,complete:boolean,works:Work[]}.
Agent uploads local covers using POST /api/v1/agent/covers Content-Type image/jpeg or image/png raw bytes -> {url}; max 8 MB. Scan File.relative_path relative to configured root, size in bytes, modified_at RFC3339. Work.code normalized uppercase, may be empty for unidentified; id optional. Agent scans video extensions mp4,mkv,avi,mov,wmv,m4v,webm; reads sibling stem.nfo then movie.nfo; folder movie.nfo groups files, stem NFO may share code. Default scan kind from top folder. Never move files. No arbitrary shell via remote payload. Launch jobs payload {tool_id}; scan jobs {library_id}. Agent accepts only locally allowlisted roots/tools from agent JSON config; server configuration cannot grant local execution access.
GET/POST /api/v1/downloaders; downloader {id,name,url,username,password,device_id(optional)}; GET /api/v1/downloaders/{id}/torrents; POST .../{id}/action {action,start/stop/delete,hashes,delete_files:false}; POST .../{id}/add {url,code,save_path,category}; credentials redacted GET.
GET/POST /api/v1/feeds {id,name,url,include,exclude}; POST /api/v1/feeds/{id}/refresh; GET /api/v1/candidates -> [{id,code,title,url,source,owned,in_queue,status}]; POST /api/v1/candidates/{id}/download {downloader_id,save_path,category}; PATCH /api/v1/candidates/{id} {status:ignored}.
GET /api/v1/recommendations -> [{work:Work,reason,score}]; GET /api/v1/actor-recommendations -> [{name,reason,score}]; GET /api/v1/catalog?actor=; POST /api/v1/catalog/sync {actor,source}; source adapters may return explicit unavailable, never fabricate complete.
GET /api/v1/settings -> JSON; PATCH /api/v1/settings JSON; GET /api/v1/backup returns database export JSON, POST /api/v1/restore accepts it (confirmation UI required).
Frontend builds dist; server serves web/dist if present via env MEDIASHELF_WEB_DIR. UI dev proxy /api -> localhost:8765. All UI Chinese.

Work.actor_thumbs is an optional actor-name -> image URL map. Actor.avatar_url is resolved from scanned NFO/local avatars, with explicit actor policy override. Only HTTP(S) without URL credentials or /covers/ URLs are accepted. Actor policy PATCH is partial and preserves aliases/avatar fields. Privacy mode must remove image nodes AND image layout regions (no poster placeholders); avatar images/initials render only outside privacy mode.

Auth: login returns {token,expires_at}, fixed 48h. auth_sessions stores only token_hash and expires_at; GET /api/v1/session validates bearer and reports expiry, including after restart. Browser remember-login uses localStorage, unchecked uses sessionStorage; never clear a new session because an older refresh returned 401.
Source registry GET /sources exposes explicit supports_actor_catalog/supports_recommendations. Source IDs javdbui,javdb,javlibrary,fanza,javbus,jav321. POST /catalog/refresh {source:javdbui,pages:2} imports public recommendation metadata only, max3 latest pages and16 detail enrichments at concurrency4; never enqueue downloads. javdbui Metadata.provider_id identifies detail records. Cached provider actor suggestions must be labelled as site recommendations and exclude known local actors. Jav321 is lookup-only.

Global outbound proxy: GET/PATCH /settings exposes proxy_enabled(default true),proxy_url(default http://127.0.0.1:7890). POST /settings/proxy/test tests fixed Wikimedia endpoint. Public metadata, RSS and images use App.outboundProxy(); qBit/agent never proxy. Remote raster images GET /images?url= uses narrow image-only query token auth, SSRF validation, 5MiB cap and 7-day disk cache. Metadata.thumbnail_url holds an observed source thumbnail; local covers take precedence, then thumbnail, then full cover.
POST /works/batch-progress {ids:[id],progress:{compression?,cutting?,translation?,verified?}} validates and atomically updates only nonmissing in-scope files; preserve unspecified per-file fields and recompute summary. Single-work collection_status is legacy storage only, hidden in UI.
Actor.favorite boolean is independent of collection policy. JavLibrary read-only import GET/PUT /accounts/javlibrary, POST /accounts/javlibrary/sync {kinds:[wanted,favorites,actors]}; session cookie redacted. Imported movies are metadata_only candidates with source_url and no download URL; download handler MUST reject metadata_only before contacting qBit. Imported favorite actors preserve policies. Outbound actor favorite writes remain unverified and must not be reported as synced.

Actor recommendation gender must be explicitly female from normalized provider metadata or Wikidata P21; exclude male, unknown and conflicts. POST /actors/{name}/profile/translate reads cached public biography only, prefers same-QID zhwiki, otherwise uses MyMemory public GET API with <=500-byte UTF-8 segments. Validate business status/quota and nonempty translation before atomic cache merge. Preserve original/source, keep hash-valid translation on unchanged wiki refresh; never send local files, collection data or account secrets for translation.

GET /collection-plan derives {actors,items,summary,generated_at} from cached catalog, explicit complete/selective actor policies and local available files; follow policies do not appear. Selective target subtracts owned, aliases/code normalization dedupe across providers and actors. Queue status is DB candidate submission state only; no live qBit call. PATCH /collection-plan/{id} {status:ignored|planned} stores reversible manual state, submitted queue wins. No automatic downloads. Actor profile biography is a 1200-rune excerpt of lead and career/life sections; preserve source links and trim irrelevant filmography/references.

JavDB UI actor catalog sync uses exact typed actor search and detail identity/type validation, then the observed /v1/movies/tags actor filter used by the public frontend. Respect max-page/timeout budgets and explicit continuation fields; never mark capped/failed pagination complete or bypass browser challenges.

Devices GET/POST /devices, GET/PATCH/DELETE /devices/{id}, GET /devices/{id}/deletion-preview. Editable fields only name,host; token/id/last_seen immutable via PATCH. Hard delete transaction removes owned libraries/tools/downloaders/jobs/candidates and owned work files (including archived rows); delete works with no remaining files, retain shared work metadata and recalculate progress. Never touch filesystem media. Agent operations and lifecycle writes synchronize so old authenticated requests cannot resurrect removed records. Online ordinary covers may use authenticated redirect=1 with validated public destination and no-referrer; encrypted CDN images retain decode proxy.
