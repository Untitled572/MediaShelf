# 实施计划与交付范围

## 1. 基础服务与本地索引

Go 服务、SQLite、中文浅色 Vue WebUI、登录、Docker、Windows 连接程序。连接程序只读已授权目录，导入 JavSP NFO 与封面；同编号跨库合并、文件缺失状态、0–5 个人评分、分文件处理进度、演员与年份筛选。已实现。

## 2. 本机工具联动

本机白名单控制可执行程序、固定参数和工作目录；WebUI 下发启动任务，连接程序启动 JavSP、BlackWhiteSplitter、WhisperJAV。三个工具内部由用户手动操作，不自动认定处理完成。已实现，具体运行证据见验收记录。

## 3. 下载与新增

本机 qBittorrent 按已有分类自动管理；远程不自动分类。下载暂存和 Syncthing 落地目录纳入查重。实现任务列表、启停、标签、分类、限速、移除任务保留文件、RSS 候选与提交前本地/队列查重。已实现；外部 API 真实与合成验证分开记录。

## 4. 演员目录与推荐

独立演员关注、别名、尽量收全/精选/仅关注策略，目录分页、已拥有与待补列表、合集与高评分筛选、基于演员/标签/评分的作品和演员推荐。已实现。外站可能限制访问，分页失败不能视作收全，不承诺来源覆盖全部作品。

## 5. 运行与验收

设备心跳、任务记录、封面缩略缓存、扫描重试日志、托盘与启动脚本、元数据备份、Windows/Linux CI、真实 Docker 部署。NSFW 隐私模式默认开启，禁止当前页面创建图片及外站 iframe。已实现；验收未通过或依赖外站环境的项目在 ACCEPTANCE.md 中保留，不能用模拟测试替代。

不在此次自动化范围：移动/删除媒体、无人审核订阅下载、自动执行重型转录或裁剪、绕过站点验证码与嵌入限制。
